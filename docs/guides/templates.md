# 课程章节与资料模板

## 课程章节

```markdown
---
title: 章节名称
description: 一句话说明本页解决的问题。
status: 草稿
tags:
  - 概念名称
---

# 章节名称

## 学习目标
- 学完应能独立解释或完成什么？

## 前置知识
需要先看哪些章节？给出相对链接。

## 核心内容
概念、物理图像、推导、适用条件与课件页码。

## 本章小结
总结结论与边界条件。

## 自测与练习
先写问题，再用折叠块放答案。

## 下一步
链接到下一章或对应习题。
```

状态按实际使用“草稿”“已整理”或“待补充”（对应导航栏图标与说明）；`tags` 列表会自动汇总到[标签索引](../tags.md)。页面底部自动展示 Git 最后修改日期，无需手动维护 `updated` 字段。

## 资料说明

```markdown
### 资料标题
- 用途：支持哪个概念或问题？
- 来源：作者、题名、年份及原始链接；不清楚时标记待补充。
- 文件：[阅读 PDF](../assets/course-name/reference.pdf)
- 格式与大小：PDF／PPTX，约多少 MiB；PPTX 下载后用演示软件打开。
- 版本与许可：版次、更新日期；本地副本注明许可、署名和是否修改。
- 使用位置：[对应章节](../courses/course-name/topic.md)
- 阅读记录：关键结论、适用条件与尚待核实的问题。
```

保存新文章后加入 `mkdocs.yml` 导航。新栏目在首页添加入口，附件在正文或资料页提供阅读链接；发布时会检查这些关系。

## 课件与参考书怎样安排

课程概览集中列出课件编号、原名、页数、大小及对应笔记；每章开头再放本章下载和两三个配套阅读入口。PPTX 使用稳定文件路径，下载时保留原名，不嵌入需要第三方服务的在线播放器。大文件只在点击后下载。

参考资料保留作者、题名、版本、使用主题及官方入口。有明确再分发许可时可附阅读副本，并注明来源、许可和修改情况；只有公开阅读地址时链接到原站；商业教材提供出版社或馆藏入口。全文与章节 PDF 分开标注，不把讲义草稿当作正式出版版。

原始课件上传前核对页数、压缩包完整性及 SHA-256；不要把整个 `ref/` 一并提交。固体物理现有文件的记录见[课件校验清单](../assets/solid-state/slides/manifest.json)。

这套安排参考了 [David Tong 的完整／分章讲义与习题目录](https://davidtong.org/teaching/solid-state-physics/)、[ETH 的讲义／Slides／习题归档](https://edu.itp.phys.ethz.ch/fs14/sst/)和 [CS 自学指南的课程资料入口](https://csdiy.wiki/%E6%95%B0%E5%AD%A6%E5%9F%BA%E7%A1%80/MITLA/)。
