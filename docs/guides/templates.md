# 课程章节与资料模板

## 课程章节

```markdown
---
title: 章节名称
description: 一句话说明本页解决的问题。
status: 草稿
updated: "2026-10-19"
---

# 章节名称

## 学习目标
- 学完应能独立解释或完成什么？

## 前置知识
需要先看哪些章节？给出相对链接。

## 核心内容
概念、物理图像、推导、适用条件与课件页码。

## 本章小结
总结结论与边界条件。

## 自测与练习
先写问题，再用折叠块放答案。

## 下一步
链接到下一章或对应习题。
```

状态按实际使用“草稿”“已整理”或“待补充”；有复核记录后再标注复核情况。日期表示内容更新，不能只因重新部署就修改日期。

## 资料说明

```markdown
### 资料标题
- 用途：支持哪个概念或问题？
- 来源：作者、题名、年份及原始链接；不清楚时标记待补充。
- 文件：[阅读 PDF](../assets/course-name/reference.pdf)
- 使用位置：[对应章节](../courses/course-name/topic.md)
- 阅读记录：关键结论、适用条件与尚待核实的问题。
```

保存新文章后加入 `mkdocs.yml` 导航。新栏目在首页添加入口，附件在正文或资料页提供阅读链接；发布时会检查这些关系。
