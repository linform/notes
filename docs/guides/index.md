# 写作与发布

## 日常流程

1. 在 `docs/` 内编辑笔记，填写标题和说明，并加入相应导航。
2. 保存文件，在本地预览中检查正文、公式、图片和链接。
3. 完成后双击桌面“笔记单次同步”，或运行 `publish-notes.ps1`。
4. 查看 [GitHub Actions](https://github.com/linform/notes/actions)，等待本次提交部署成功。

保存不会自动上传。快捷方式执行一轮后保留结果窗口；后台轮询和登录自启保持关闭。

## 写作工具

- [Markdown 使用手册](../Markdown使用说明.md)：标题、公式、图片、表格和发布说明。
- [课程章节与资料模板](templates.md)：复制后填写标题、目标、来源和正文。

## 发布失败时

先读结果窗口中的具体原因。内容入口遗漏、链接失效或构建失败时，修正后重试；网络失败时本地提交仍保留。远端领先或发生冲突时先检查差异并安全整合，之后重试。

## 纠错

课程页面可用“编辑此页”定位源文件，也可[提交问题](https://github.com/linform/notes/issues/new)。说明页面地址、章节标题、预期内容和依据，便于复核。
